# THE NIGHT SHIFT PLANNING

Application iPhone installable pour gérer les services de nuit, repos, congés, remplacements et heures travaillées.

Installation : ouvrez l’application dans Safari, touchez **Partager**, puis **Sur l’écran d’accueil**.

Icône : la source 4K est incluse ; les fichiers icon-1024.png, icon-512.png, icon-192.png et apple-touch-icon.png sont dérivés de cette image. Sur iPhone, après publication, supprimer l’ancienne icône de l’écran d’accueil puis ajouter à nouveau l’application si iOS conserve l’image précédente.
